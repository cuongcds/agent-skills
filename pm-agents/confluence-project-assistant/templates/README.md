# Project Documentation Workspace

This workspace is managed by `confluence-project-assistant`.

- Put newly received/unclassified source documents in `uncategorized/`.
- Say **"có tài liệu mới"** to trigger document classification and synchronization.
- Original documents are preserved in `source-documents/`, under the appropriate numbered project domain.
- `pm-area/source-map.md` lists every document in `source-documents/` with its added/updated dates.
- `confluence-pages/` contains curated Markdown intended for Confluence.
- `pm-area/` contains internal Markdown and is never published to Confluence.
