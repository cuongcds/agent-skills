# Conflict Resolution Reference

When new source material conflicts with existing project knowledge:

1. Record both claims.
2. Record source paths (relative to `source-documents/`, without that prefix).
3. Compare source date/version and authority if available; `pm-area/source-map.md` gives the added/updated dates.
4. Prefer the clearly newer/approved source.
5. If authority is unclear, do not silently choose.
6. Record the unresolved conflict in `pm-area` and report it.
7. Update `confluence-pages` only when the canonical interpretation is sufficiently supported.
